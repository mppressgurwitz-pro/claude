# claude

Очередь публикации статических страниц на сайты Quantum Plus. Порядок работы — [deploy/README.md](deploy/README.md) (канон с 30.10.2026).

Приложения, тестов, зависимостей и CI в репозитории нет. На сайты уходит только дерево `deploy/`.

## Файлы

| Путь | Что это |
|---|---|
| `deploy/README.md` | Папка выкладки, префиксы `z` `k` `c` `x`, домены, ограничения |
| `deploy/events/k1/index.html` | Пример страницы: канал Kimi, номер 1, сайт events |

## Перед коммитом

1. Прочитай `deploy/README.md`.
2. Сверь папку с примером `deploy/events/k1/`: файл `index.html` лежит в корне `<префикс><номер>/`, в `<head>` есть `<meta name="robots" content="noindex, nofollow">`, имена файлов латиницей.
3. Коммит и push в `main`. После синка проверь тело ответа по уникальной строке из своего `index.html`. Команда и наблюдение от 2026-11-02 — в `deploy/README.md`, раздел «Проверка тела».
