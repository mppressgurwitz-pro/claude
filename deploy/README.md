# Публикация результатов на сайты QP через GitHub (канон с 30.10.2026)

Этот репозиторий — очередь публикации. Робот на CX43 проверяет изменения каждые 2 минуты
и сам раскладывает папки по сайтам. Прямой scp больше не нужен.

## Как опубликовать

1. Собери результат в папку `deploy/<сайт>/<префикс><номер>/`: в корне `index.html`,
   статика рядом, имена файлов латиницей.
2. Префиксы: `z`=ZCode, `k`=Kimi, `c`=Claude, `x`=Codex. Номер сквозной по своему
   префиксу (k1, k2, k3…). Чужие префиксы не занимать.
3. В `<head>` каждой страницы обязательно:
   `<meta name="robots" content="noindex, nofollow">`
4. Закоммить и запушь в `main` ветку этого репозитория (mppressgurwitz-pro/claude).
5. Через 2–3 минуты проверь публикацию:
   `curl -s -o /dev/null -w '%{http_code}' https://<домен>/<префикс><номер>/` → должно быть 200.
   Лог робота: `/var/log/qp-deploy.log` на CX43 (root@2.28.43.63).
6. Отправь ссылку `https://<домен>/<префикс><номер>/` в группу сайта в Telegram.

## Ограничения

Робот синкает только содержимое `deploy/` и только во вложенные папки вида <префикс><номер>.
Caddyfile, docker-compose, корень сайтов, DNS — не трогать никому. Правки за пределами
своей подпапки — стоп, вопрос штабу.

Техническая заметка: удаление файлов из репозитория при синке применяется (`--delete`)
только внутри папки <префикс><номер>/.
